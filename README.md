# TIDELIGHT: Quiet Current

![TIDELIGHT: Quiet Current](media/capsule.png)

A quiet 3D connection puzzle. Turn the network across miniature islands, follow the golden paths, and bring every island back to light.

**[Play the current free Windows demo on itch.io](https://zeldious-studio.itch.io/tidelight-quiet-current-demo)** · **[Official website](https://tidelight-quiet-current.zeldious.chatgpt.site)** · **[Player feedback](https://github.com/Zeldious-Studio-Company/tidelight-quiet-current/issues)**

Four playable levels. English and French, local saves, undo, hints, optional sound and reduced motion. Mouse and keyboard. Works offline.

The entire demo is free. If these four islands gave you a good moment, an optional $2 tip on itch.io is a lovely way to say thanks. You can return after playing. Everyone gets the same demo, including at zero. Support does not include the full game, a future key or a promise of extra content.

## Play

1. Get the current Windows x64 demo from [itch.io](https://zeldious-studio.itch.io/tidelight-quiet-current-demo).
2. For a free download, choose “No thanks, just take me to the downloads”.
3. Extract the complete ZIP, then run `Tidelight-Demo.exe`. Keep `data_Tidelight_windows_x86_64` next to it.

The .NET runtime is included; Godot does not need to be installed. Windows 64-bit only. The executable is unsigned. Compatibility with other systems has not been verified.

Left click / E / Space: rotate. Right click / Q: reverse. Arrows: select. U: undo. H: hint. Esc: menu. F11: full screen. P: hide UI. Connect every island to the lighthouse with no open ends.
